# 🐾 Ruffles, Wispa & Rogan — Classroom Volume Monitor

**Live Classroom Link:** https://mrsmithchps.github.io/sound-monitor-chps/

A school classroom noise monitor featuring **Ruffles**, **Wispa**, and **Rogan**. Choose which dog(s) are visiting class today (any 1, any 2, or all 3!). While the classroom stays calm and focused, they sleep peacefully; if the room gets chatty they begin to stir, and if it gets too loud they wake right up!

## Features
- **Choose Your Classroom Dogs**: Pick any combination of **Ruffles**, **Wispa**, and **Rogan** right on the start screen, in Settings, or by clicking their Polaroid photos.
- **Hide Noise Meter Mode (`🙈 Hide Meter`)**: Hide the live noise meter so children focus on keeping the sleeping dogs calm rather than watching or testing the volume bar.
- **3-Stage Live Volume Feedback**: *Sleeping* (`💤`), *Stirring* (`👂`), and *Wide Awake* (`🐶`)
- **Classroom Activity Presets**: Silent Reading, Partner Whisper, Group Work, and Busy Makers
- **Draggable Wake-Up Line & Mic Sensitivity Controls**
- **Quiet Streak Timer & Dream Treats (`🦴`)**
- **100% Private**: Audio is measured locally in the browser using the Web Audio API and is never recorded or transmitted anywhere.
